# 01. 要件定義

## 1. 機能要件

### プレイヤー

- 三人称視点で移動できる
- ゲームパッドとキーボード・マウスで同等に操作できる
- ジャンプできる
- 空中攻撃を実行できる
- ソフトロックを使用できる
- 手動ロックオンを使用できる
- ロックオン対象を切り替えられる
- 剣、斧、弓をチェックポイントで変更できる
- 戦闘中は武器を変更できない
- 通常攻撃と強攻撃を組み合わせられる
- 攻撃と回避でスタミナを消費する
- スタミナ不足時は対象行動を実行できない
- スタミナ枯渇時に息切れ状態となる
- ジャスト回避を実行できる
- ジャスト回避後に武器固有反撃を実行できる
- 剣でパリィできる
- 斧でガードまたは受け止めを実行できる
- 回数制限付き回復アイテムを使用できる

### 敵

- 近接通常敵を実装する
- 遠距離通常敵を実装する
- 通常戦で複数の敵が同時に行動する
- 同時に近接攻撃する敵を最大2体に制限する
- 近接攻撃枠と遠距離攻撃枠を分離する
- HPと体勢値を持つ
- 体勢値が0になるとダウンする
- ダウン時に専用致命攻撃を受ける
- 敵ごとに体勢値の回復設定を変更できる

### ボス

- 1対1で戦う
- HP50%以下で第2フェーズへ移行する
- プレイヤーとの距離を評価する
- プレイヤーの装備武器を評価する
- プレイヤーの回復状態を評価する
- プレイヤーの残りスタミナを評価する
- 直近数秒の行動と戦闘全体の傾向を評価する
- 状況に応じて攻撃候補の評価値を変更する
- 状況に応じて接近・離脱頻度を変更する
- 状況に応じて遠距離攻撃頻度を変更する
- 攻撃コンボを分岐できる
- 特定攻撃後に大きな隙を持つ
- ジャスト回避またはパリィ成功時に反撃可能な隙を作る
- 弓で距離を取られた場合に専用接近行動を選択できる

### ステージ・進行

- 導入テキストを表示する
- チュートリアルを実施する
- チェックポイントを使用できる
- チェックポイント使用時に通常敵が復活する
- チェックポイントで回復アイテムを補充する
- チェックポイントで武器を変更する
- チェックポイントで武器を強化する
- 死亡時に強化素材を落とす
- 落とした素材を回収できる
- 回収前に再死亡すると以前の素材が消滅する
- ボス登場演出は工数に余裕がある場合に実装する

### セーブ

- セーブスロットは1つ
- チェックポイント使用時にオートセーブする
- 武器強化時にオートセーブする
- ボス撃破時にオートセーブする
- ステージクリア時にオートセーブする
- 設定変更時に設定データを保存する
- Steam CloudはSteam公開版の追加要件とする

## 2. 非機能要件

### パフォーマンス

- 1920x1080を基準解像度候補とする
- 60fpsを最低保証目標とする
- 120fpsを挑戦目標とする
- RTX 3060搭載開発環境で継続的に計測する
- 平均fpsだけでなくフレーム時間を確認する
- Game Thread、Render Thread、GPUのボトルネックを分離する

### 保守性

- 武器、攻撃、敵、Abilityをデータ駆動で追加できる
- C++とBlueprintの責務を分離する
- キャラクター移動実装をインターフェースで抽象化する
- Moverを不採用にしても戦闘システムへ影響させない
- Gameplay Tagで状態を一元管理する
- Tickの使用を必要なクラスに限定する

### 品質

- 進行不能バグを0件にする
- 既知のクラッシュを0件にする
- ゲームパッドとキーボード・マウスの両方でクリア確認を行う
- セーブ破損時の挙動を確認する
- 長時間プレイでメモリ増加を確認する
- Shippingビルドで最終確認を行う

## 3. 対象外

Vertical Sliceでは次を対象外とします。

- オンラインマルチプレイ
- ネットワーク同期
- Epic Online Services連携
- Steam Cloud
- 複数ロックオン部位
- リアルタイム武器切り替え
- 空中コンボ
- 大規模なストーリー
- フルボイス
