## 2. 戦闘テスト

```text
TC-COMBAT-001
目的 : スタミナ不足時に攻撃できない
前提 : Stamina < AttackCost
操作 : 通常攻撃入力
期待 : Abilityが発動せず、誤ったコスト消費もない

TC-COMBAT-002
目的 : ジャスト回避成功後に反撃可能
前提 : PerfectDodge Window内
操作 : 回避成功後に攻撃入力
期待 : 武器固有Counter Abilityが発動する

TC-COMBAT-003
目的 : 反撃受付時間切れ
前提 : PerfectDodge成功
操作 : 入力せず受付時間を超過
期待 : Counter Tagが解除され通常攻撃になる
```

## 3. AIテスト

- 同一攻撃の過剰連続を避ける
- 距離に合わない攻撃を選択しない
- 弓で遠距離維持した場合に接近行動を選択する
- 回復中のプレイヤーを評価する
- 未反映入力を参照しない
- Phase2で攻撃候補が変化する
- AIデバッグ値と実際の選択が一致する

## 4. 集団戦テスト

- 近接攻撃枠が2体を超えない
- 攻撃終了後に枠を解放する
- 死亡・ダウン・中断時にも枠を解放する
- 遠距離枠が近接枠と独立している
- 長時間待機した敵の優先度が上がる
- 画面外攻撃が不公平にならない

## 5. セーブテスト

- チェックポイント保存
- 武器強化保存
- ステージクリア保存
- 設定保存
- 古いSaveVersionの移行
- 保存中断時の破損対策
- 不正値の検出

## 6. 性能テスト

- 各計測地点で60fpsを確認
- ボスPhase2でフレーム時間を確認
- 長時間プレイでメモリ増加を確認
- Shippingビルドで計測
- デバッグ表示無効時の負荷を確認
