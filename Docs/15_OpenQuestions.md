# 15. 未確定事項・プロトタイプ検証項目

これらは初期実装を止める要因ではありません。Vertical Sliceまでに検証して確定します。

- 世界観

  - 人型
  - 獣型
  - 大型怪物

  - 武器別ステップ
  - ローリング

- 回復アイテム所持数
- 回復量
- 回復時間

## 3. 弓

- 通常攻撃を3段コンボにするか連続射撃にするか

## 4. 斧

- ガードか受け止めか

- ガードブレイク
- スーパーアーマーの対象攻撃

## 5. Mover

段階導入で比較します。

```text
評価項目
  |
  +--> 入力応答性
  +--> Root Motion連携
  +--> Motion Warping連携
  +--> ジャンプ
  +--> 回避
  +--> 斜面
  +--> 段差
  +--> パフォーマンス
  +--> デバッグ容易性
  +--> Shippingビルド安定性
```

2～3週間の検証後に次を決定します。

- Moverを継続
- CharacterMovementComponentへ移行
- 一部のみMoverを使用
