## 5. 技術説明の軸

### C++とBlueprintの分担

```text
C++
  |
  +--> 戦闘ロジック
  +--> Ability
  +--> AI評価
  +--> セーブ
  +--> データ検証
  +--> デバッグ
  +--> Subsystem
  +--> 共通基盤

Blueprint
  |
  +--> レベル配置
  +--> アセット参照
  +--> VFX・SE設定
  +--> アニメーション接続
  +--> データ調整
  +--> 演出調整
```

### AIの説明

- 入力を直接読まない
- 確定済み状態だけを参照する
- 直近履歴と全体傾向を分離する
- 攻撃評価値の内訳を可視化する
- StateTree、Behavior Tree、C++の責務を説明する

### Moverの説明

- Experimental機能であることを理解している
- 2～3週間の段階検証を行う
- Movement Driverで交換可能にする
- 採否と比較結果を記録する
